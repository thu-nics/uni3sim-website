    05 / PUTTING SCHEDULING BACK INTO THE SYSTEM

    The CPU prepares.
    The device computes. Who is waiting?

    Preparing the next batch early can reduce device idle time while waiting for the CPU. Compute durations stay the same; the scheduling relationship changes.

    TTFT

    Time to first token

    From request arrival to the first visible output token.

    TPOT

    Time per output token

    Time between the first and last output tokens ÷ (output token count − 1), for outputs longer than one token.

    THROUGHPUT

    Output throughput

    Output tokens divided by elapsed time within the stated observation window.

    ProtoBridge

    Make supernode interconnect protocol differences explicit through packet execution and dependencies.

    Modeling focus ＋
    • Translation from communication operators to packets
    • Protocol parameters and packet dependencies
    • A shared packet execution module
